# Product Manager App (Vite + React)

A responsive React single-page application (SPA) built with **Vite** for managing a list of products.  
It demonstrates modern front-end development skills — responsive UI design, interactivity, API integration, and state management.

---

## Features

- View, add, edit, and delete products
- Inline editing for product details
- Input validation (name and price)
- Responsive design using Flexbox and media queries
- RESTful API integration using **json-server**
- State management with **React Context API**
- Built with modern ES6+ JavaScript features

---

## Tech Stack

- **Vite + React (Frontend Framework)**
- **Axios** – API communication
- **json-server** – Mock REST API
- **CSS3 / Flexbox** – Layout and responsiveness
